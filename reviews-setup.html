Set Up the Review Finder

The review finder looks up professional critics’ reviews for each wine you reveal (Decanter, James Suckling, Wine Enthusiast and others) and shows the critic, score and a one-line summary on the wine’s page. It runs free in your own Google account using Google’s Gemini AI with Google Search. Set-up takes about ten minutes on a computer, and you only do it once.

Friends who use the app don’t need to repeat this: send them the link you get in step 4, and they paste it into their Settings.

1. Get a free Gemini key

  1. Go to aistudio.google.com/apikey and sign in with your Google account.
  2. Tap Create API key. If asked, let it create a new project.
  3. Copy the key (a long code starting with AIza). No billing or card is needed.

2. Create the script

  1. Go to script.google.com. A new project opens with a file called Code.gs.
  2. Delete what’s in it, then paste the review finder script:
  3. Click the project name (“Untitled project”) and name it Tasting Notes Reviews. Click the save icon.

3. Add your key

  1. In the left sidebar, click the gear (Project Settings).
  2. Scroll to Script Properties, click Add script property.
  3. Property: GEMINI_KEY. Value: the key from step 1. Click Save script properties.

4. Deploy it

  1. Click Deploy (top right), then New deployment.
  2. Click the gear next to “Select type” and choose Web app.
  3. Set Execute as to Me and Who has access to Anyone. Click Deploy.
  4. Google asks you to authorize: choose your account. If you see “Google hasn’t verified this app,” click Advanced, then Go to Tasting Notes Reviews, then Allow. (It’s your own script; the warning appears for every personal script.)
  5. Copy the Web app URL (it starts with https://script.google.com/macros/s/).

5. Connect the app

  1. In Tasting Notes, open Settings › Professional Reviews.
  2. Paste the link and tap Save and Test. It should say “Connected.”
  3. Open any revealed wine in the Notebook. Reviews appear under Professional reviews after a few seconds and are saved with the wine.

Good to know

  • What’s sent: only the wine’s producer and name, vintage, grape, region and country, from the app to your script and on to Google’s Gemini. Nothing else from your notes.
  • Accuracy: a review is shown only if Gemini found its web page in a Google search. Summaries are written by Gemini, not quoted, and each links to its source. A review for a different vintage is marked.
  • Paywalls: for subscriber-only reviews (James Suckling, Decanter Premium and others) usually only the score and a line are public, so those summaries are short.
  • Free limits: the script stops after 150 searches a day, well within Google’s free allowance. Each wine is searched once; tap Search again on a wine to refresh it.
  • Google’s terms: on the free plan, Google may use requests to improve its products. Only wine names are sent.
  • Turning it off: remove the link in Settings, or delete the script at script.google.com.
